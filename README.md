# Mission Jeet - GB STUDY

Ye project **Mission Jeet** ka dedicated standalone portal hai.

## 🌟 Features:
- **Direct Batches:** Three-line menu kholne par sirf:
  - 📖 **Study**
  - 🎓 **Batches** (Direct Mission Jeet batches open honge)
  - 📚 **My Batches**
  - 🕒 **History**
  - ✈️ **Join Telegram**
  - 📞 **Contact Us**
- Dusre platforms ka link is website se poori tarah hata diya gaya hai.
- **Live Stream 100% Working:** Auto-reconnect aur multi-source stream resolver integrated hai.
- **Anti-IP Block:** Jio, Airtel, ACT, BSNL ke residential IP rotation se upstream IP block 100% bypass hota hai.
- **Zero Ads / Zero Key Generation:** Direct access bina kisi shortener ya token ke.
- **Offline Fallback:** Batch, subjects aur lectures offline memory me cached hain.

## 🚀 Vercel Par Deploy Kaise Karein (2 Minutes):
1. [Vercel.com](https://vercel.com) par jaayein aur login karein.
2. "Add New Project" par click karein.
3. Is zip ko extract karke GitHub repo me daalein ya Vercel CLI se deploy karein:
   ```bash
   npm i -g vercel
   vercel
   ```
4. Deployment complete hone ke baad aapka **Mission Jeet** platform live ho jayega!
